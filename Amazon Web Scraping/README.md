# Amazon Web Scraping

## Beautiful Soup tool
Beautiful Soup is Python library used for parsing HTML and XML documents,
It creates a parse tree for parsed pages, which can be used to extract data 
from HTML, I used Beautiful Soup to scrape data about perfumes from 
Amazon.  


# The extracted data included: 
Rating: Customer ratings of the products. 
Prices: The listed prices of the perfumes. 
Reviews Count: The number of customer reviews for each product. 
Options: Various options available for each product (eg., sizes, scents). 
Discount Price: The discounted prices, if any. 
Name of Product: The names of the perfumes. 
This process resulted in approximately 15,200 rows of data. The reusability of 
the code was a key focus, ensuring that the scraping script could be easily 
adapted for similar tasks in the future. The data gathered was useful, 
providing insights into customer preferences and market trends.





# ETHICAL CONSIDERATIONS 
While web scraping is a powerful tool, it must be used ethically, Here are 
some ethical considerations to keep in mind: -Permission and Terms of Service 
Always check the websits terms of service and obtain permission if 
necessary before scraping. Some websites explicitly prohibit scraping, and 
violating these terms can lead to legal repercussions, Respecting the 
websits policies ensures that the scraping activity is legal and ethical. -Data Sharing 
Do not share or sell the scraped data if the website does not allow it. 
Unauthorized sharing of data can lead to privacy violations and damage the 
reputation of both the scraper and the data source. Its crucial to handle the 
data responsibly and ensure it is used for legitimate purposes only. -Responsible Use 
Use the data responsibly. Scraped data should be used to generate positive 
outcomes, such as improving products or services, rather than for malicious 
purposes. Ethical use of data fosters trust and promotes the constructive 
application of technology. -Transparency 
Be transparent about the data collection process. If the data is to be used for 
research or published in any form, disclose how the data was collected and 
ensure that it does not infringe on privacy or intellectual property rights. 
Transparency builds credibility and trust in the data analysis process.
